# AttentionSeekers: Mid-Submission Plan (Team Overview)

**Goal for mid-sub:** a working pipeline on **Qwen2.5-7B-Instruct**, **2 traits (Extraversion, Agreeableness)**, and 2–3 real preliminary results. Negative results are fine. A corrected methodology is part of the deliverable.

**Out of scope for mid-sub:** Llama, all 5 traits, the full intervention study, and multi-turn drift. These all move to Oct–Nov.

---

## The three questions we want early answers to

1. Do the Style Modulation Heads (SMHs) still show up for **Big Five** traits, or only for Izawa's six personas?
2. Does **user** style land on the **same heads** as **assigned** (system-prompt) persona?
3. Does Qwen actually **mirror** user style in its outputs in a single turn?

---

## Workstream 1: Data Creation
**Owner(s):** ______

- 20 base scenarios (4 domains × 5): user intent, a neutral user message, and one fixed assistant response generated by Qwen itself.
- **User-style variants:** E and A, high and low pole, 3 paraphrases each. That gives 240 items.
- **Assigned-persona twin set:** the same scenarios and the same fixed response, with the style moved into the **system prompt** (high or low pole, 5 paraphrased prompts per pole).
- **Factorial set (small):** assigned {high, low, none} × user {high, low} for 1 trait.
- **QC:** an LLM judge checks content preservation and trait realization; failures are regenerated. Hand-check about 10% of items.
- **Output:** JSONL files in one agreed schema (see the agent plan). **This blocks everything else, so ship a first slice early** (5 scenarios, 1 trait).

## Workstream 2: SMH Experiments & Reproducibility
**Owner(s):** ______

- Run Izawa et al.'s repo on Qwen. **Reproduce** SMHs at `layers[19]`, heads `[2, 4, 27]` (the paper's numbering is 1-indexed).
- Build our own activation-extraction hooks and **match their numbers** on one trait. This validates our code.
- Rerun head localization with **Big Five system prompts** (our twin set). Do the SMHs survive?
- Define the **control head groups** (random 3 heads in the same layer, highest-norm 3 heads).
- **Output:** a head-score heatmap for assigned persona, a reproduction check, and a verified extraction module other workstreams can reuse.

## Workstream 3: User-Induced Experiments on Qwen
**Owner(s):** ______

- **Behavioral mirroring check:** generate responses to high- vs low-pole user messages. The judge scores the model's trait **without seeing the user message**. Does Qwen mirror?
- **User-style head localization:** the same head-score analysis, with the contrast coming from the **user** instead of the system prompt. Compare with Workstream 2's heatmap.
- **Geometry (stretch):** a small factorial regression on SMH activations. Does the user direction align with the assigned direction?
- **Stretch 2:** zero-ablate the SMHs and check whether mirroring drops.
- **Output:** a mirroring effect size, an assigned-vs-user head comparison, and (if time allows) an alignment cosine with CI.

## Design fixes we're adopting (vs. the proposal)

- Read activations at **three positions**: the first assistant token, the mean over response tokens, and the mean over user tokens. The first-token readout is unaffected by teacher-forcing, so the old design wasn't using teacher-forcing at all.
- Sampled completions are **not** replicates for first-token activations. Use paraphrases as replicates instead.
- Localize heads **separately** for user-style and assigned-persona contrasts. This makes RQ2 a direct comparison and avoids selection bias from SMHs having been chosen using system prompts.
- Scope claims to **single-turn mirroring**. Persona drift becomes an extension.
